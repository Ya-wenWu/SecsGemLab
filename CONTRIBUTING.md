# Contributing

Thanks for your interest! This is a learning lab, so all skill levels welcome.

## How to Contribute

1. **Fork** the repo
2. **Create a branch** (`git checkout -b feature/your-idea`)
3. **Make your changes**
4. **Run tests** (`dotnet test`)
5. **Commit** with a [conventional commit](https://www.conventionalcommits.org/) message
6. **Push** and open a Pull Request

## Before Submitting

- Tests must pass (`dotnet test`)
- No hardcoded secrets or credentials
- Follow existing code style (nullable enabled, implicit usings)

## Code Review

All PRs get an automated AI code review. A maintainer will also review
within a few days.

## Questions?

Open an issue — there are no stupid questions.
