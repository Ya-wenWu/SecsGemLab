# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately:

- **GitHub Issues** — prefix the title with `[SECURITY]` for public reports
- **Email** — open a GitHub Issue and request a private channel

Do **not** file a public issue for critical vulnerabilities.

## Response

I'll acknowledge receipt within 48 hours and work on a fix as quickly as
possible. This is a personal learning project, so response times may vary.
